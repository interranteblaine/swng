- **Design decisions fixed by this plan** (do not relitigate; ⚑ = flagged for user veto at plan review):
  - **`game-terminated` is a round event** `{ kind: "game-terminated", gameId }` (envelope carries opId/hlc like every event). INVARIANT beside the interface: the fold's terminated-set is a **set union — commutative, idempotent, and tolerant of arrival before its `game-added`** (an out-of-order `game-terminated` for a not-yet-seen gameId must still terminate that game once it appears; fold any interleaving to the same state). Once terminated, always terminated — no un-terminate event in v1. Scores landing after termination still fold into cells (they're facts); the terminated game just stops consuming them.
  - **Terminated games are excluded from `settleRound`'s must-resolve set** and from `results`; they stay in the archive's `games` list and the archive records the terminated ids (`terminatedGameIds`) so the record is honest. Any participant may terminate (matches the finalize rule). Termination is an online HTTP command like addGame/finalize — NOT an offline outbox op (game management is a connected act; scores are the offline path). ⚑
  - **"End round early" is composition, not a new event:** when finalize would fail on unresolved games, the confirm dialog names them and offers "End unfinished games & finalize" — terminate each unresolved game, then the existing finalize. ⚑
  - **Cognito: email sign-in via the Hosted UI (managed login), SPA client (no secret, PKCE), ID-token Bearer auth verified IN the lambda dispatcher** (new route tier `auth: "golfer"`) via `adapters-cognito`'s `aws-jwt-verify` wrapper — NOT an API-Gateway JWT authorizer, so the declarative route table stays the single auth owner. Social sign-in deferred (needs OAuth app registrations). `USER_PASSWORD_AUTH` is enabled on the client purely so the e2e gate can mint real JWTs without automating the Hosted UI — beta-grade, goes on the M9 hardening list with token-storage-in-localStorage. ⚑
  - **Golfer items are lazy**: no GOLFER row exists until first sign-in (`GET /me` get-or-creates from the JWT's sub+email) or a claim. Claiming: signed-in golfer taps a roster row in any round they can open → `POST /golfers/claim { golferId }` binds their sub to that EXISTING GolferId, conditional on it being unclaimed (409 `golfer-already-claimed`). History is continuous by construction because nothing else moves. Round-membership-as-claim-capability is beta-grade (M9: challenge/confirmation). `GolferMerged` (claim collides with an existing account's history) is explicitly out of v1 scope — ledger it.
  - **Index precedence** (architecture §2): official (manually maintained) always wins > computed (takes over automatically once it exists — `computeIndex` returns undefined below 3 differentials, which IS the roadmap's 54-hole bootstrap) > declared. v1 profile exposes declared + computed; official is a profile field that stays null until a future milestone maintains it.
  - **9-hole combining (2020 published rule):** consecutive 9-hole differentials pair oldest-first; a pair sums into ONE 18-hole differential; an unpaired trailing 9-hole differential waits (contributes nothing until its partner posts). Implemented as a pure domain function; the projector applies it before `computeIndex`.
  - **Projections are rebuildable by replay:** the stream projector and the rebuild entry MUST run the exact same application function (`projectArchive`) — one implementation, two triggers. HISTORY items are keyed by roundId (re-finalize/stream-retry upserts idempotently). Rebuild = wipe golfer's projections, replay all archives, byte-identical result (the gate proves it).
  - **⚑ Task 7 includes the I2 "Edit this card" affordance** (recommended, still awaiting the user's formal call — if vetoed, T7 ships the AddCoursePage redesign alone and I2 reverts to a recorded scope cut). The edit flow reuses `POST /courses/{id}/tees` (same name ⇒ new version) and closes review finding M-i via an `onCourseRefreshed` callback.
  - **New-surface legibility gate:** every new page/affordance in T6–T7 gets a screenshot walk (Playwright MCP or spec screenshots) reviewed by the controller before the milestone closes — `docs/papercuts.md` §4.

**Interfaces (produced):**

```ts
// events.ts — union gains (envelope identical to every other event):
| { readonly kind: "game-terminated"; readonly gameId: GameId }

// state.ts — RoundState gains:
readonly terminatedGameIds: ReadonlySet<GameId>;
// INVARIANT: set-union fold — commutative, idempotent, order-independent, and a
// game-terminated arriving BEFORE its game-added still terminates the game (test all three
// orderings + duplicate delivery). state.games keeps terminated configs (audit); every
// DOWNSTREAM consumer decides its own filtering.

// archive.ts — settleRound: results computed ONLY for games not in terminatedGameIds
// (must-resolve set shrinks); RoundArchive gains:
readonly terminatedGameIds: readonly GameId[];   // canonical order: sorted lexicographically
// Settlement determinism suite must stay green; new test: a round with one resolved game and
// one terminated-unresolved game settles; same round WITHOUT the termination throws
// game-unresolved (pins that termination is what unlocked it).

// handicap/whs.ts:
export const combineNineHoleDifferentials = (
  entries: readonly { readonly differential: number; readonly holes: 9 | 18 }[],
): readonly number[];
// Oldest→newest in, 18-hole-equivalent differentials out: 18s pass through in place; 9s pair
// oldest-first, each pair emitting ONE differential (sum of the two) at the position of the
// SECOND of the pair; a trailing unpaired 9 emits nothing (2020 published rule — waits for a
// partner). Hand-pinned test: [18:10.0, 9:4.1, 18:12.3, 9:5.2, 9:6.0] → [10.0, 12.3, 9.3]
// (4.1+5.2 pairs across the intervening 18; trailing 6.0 waits).

// golfer/golfer.ts:
export interface HandicapProfile { readonly declared?: number; readonly official?: number; readonly computed?: number; }
export interface Golfer { readonly id: GolferId; readonly name: string; readonly homeCourseId?: CourseId; readonly handicap: HandicapProfile; }
export const effectiveIndex = (profile: HandicapProfile): { readonly value: number; readonly source: "official" | "computed" | "declared" } | undefined;
// precedence official > computed > declared; undefined when none set.

// golfer/record.ts — what one archive contributes to one golfer's record:
export interface GolferRoundLine {
  readonly roundId: RoundId; readonly courseName: string; readonly tee: string;
  readonly holes: 9 | 18; readonly ags?: number; readonly differential?: number;  // absent when handicapping row was "incomplete"
  readonly distribution: { readonly eagles: number; readonly birdies: number; readonly pars: number; readonly bogeys: number; readonly doublePlus: number };
}
export const archiveGolferLine = (archive: RoundArchive, golferId: GolferId): GolferRoundLine;
// distribution counts DECIDED stroke cells vs par (picked-up/conceded cells and unscored
// holes count nowhere); holes = the golfer's tee-set length. Test against a hand-built
// archive: 18 holes, 1 birdie/10 pars/6 bogeys/1 double → {0,1,10,6,1}.
```

```ts
  // sub already bound elsewhere via getBySub precheck) throws "golfer-already-claimed".
}

// ports/projectionStore.ts:
export interface ProjectionStore {
  putHistoryLine(golferId: GolferId, line: GolferRoundLine & { readonly finalizedAtMs: number }): Promise<void>;  // upsert by (golferId, roundId)
  listHistory(golferId: GolferId): Promise<readonly (GolferRoundLine & { readonly finalizedAtMs: number })[]>;    // oldest → newest
  putIndex(golferId: GolferId, snapshot: { readonly value: number; readonly computedAtMs: number; readonly differentialsUsed: number }): Promise<void>;
  getIndex(golferId: GolferId): Promise<{ value: number; computedAtMs: number; differentialsUsed: number } | undefined>;
  wipeGolfer(golferId: GolferId): Promise<void>;
}

// projections/projectArchive.ts — THE one projector implementation (stream + rebuild both call it):
export const projectArchive = (deps: { projectionStore; clock; logger }) => async (archive: RoundArchive): Promise<void>;
// finalizedAtMs = the round-finalized event's hlc.wallMs, read from archive.events (the
// archive always contains exactly one; throw if absent — a settled archive without it is corrupt).
// per participant: putHistoryLine(archiveGolferLine(...)); then recompute that golfer's index:
// listHistory → combineNineHoleDifferentials(lines with a differential, oldest-first)
// → computeIndex → putIndex (or skip when undefined — bootstrap not met). Idempotent by
// construction (upsert + recompute-from-scratch): projecting the same archive twice is a no-op.

// projections/rebuildProjections.ts:
export const rebuildProjections = (deps: { archiveSource: { listArchives(): AsyncIterable<RoundArchive> }; projectionStore; clock; logger }) => async (): Promise<{ rounds: number; golfers: number }>;
// wipe every touched golfer FIRST (collect from archives), then replay projectArchive over
// all archives in finalizedAt order. Same function, second trigger — no forked math.
```
